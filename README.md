# Java学習ノート

## 文字を出力したい

#### 以下のように記述

```
System.out.println("Hello, World!");
```

## 【データ型】とは

 型 | 意味 | 値の例 |
 |---|---|---|
 |int(インテジャー)|整数|85|
 |duble(ダブル)|少数を扱える数値|85.5|
 |String(ストリング)|文字列|"aya"|
 |boolean(ブーリアン)|真偽値|true|

#### 記述例

```
String name = "Taro";
int age = 25;
double height = 170.5;
```

## 【変数（箱のようなもの）】の使い方

 用語 | コード | 意味 |
 |---|---|---|
 |宣言|int age;|変数を用意する|
 |代入|age = 25;|変数に値を入れる|
 |宣言と初期化|int age = 25;|変数を作って最初の値を入れる|
 |再代入|age = 26;|変数の中身を書き換える|
 |参照|system.out.println(age);|変数の中身を読んで表示する|
