## 【データ型】とは

 型 | 意味 | 値の例 |
 |---|---|---|
 |int(インテジャー)|整数|85|
 |duble(ダブル)|少数を扱える数値|85.5|
 |String(ストリング)|文字列|"aya"|
 |boolean(ブーリアン)|真偽値|true|

#### 記述例

```
String name = "Taro";
int age = 25;
double height = 170.5;
```
